Manifest-only happy path

Select a club, change a tab, change zoom, step Age, scroll the list, and drag the title. The same generic dispatcher handles every action.

The claim that must stay honest

The Options prototype does not yet expose this dispatcher: `desktop.gd` preloads `options_window.gd`, and that file constructs every Options control explicitly. Therefore an actual Godot zero-diff comparison has no frozen shared engine baseline.

Unsupported on purpose

The candidate proves Window, Button, Tabs, Range, ScrollView, Dropdown, SelectionView and Stepper. File-system dialogs and the four-frame swing artwork remain outside this smallest tracer; they are semantic adapters/assets, not missing pointer gestures.
